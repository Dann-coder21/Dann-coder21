## 👨‍💻 About Me

I'm a software developer based in Nairobi, Kenya, interested in building reliable web applications, well-structured backend systems, and software that solves real-world problems.

My professional experience includes developing a university maintenance management system using **Laravel, Filament PHP, PostgreSQL, Redis, and Docker**, alongside experience with ASP.NET Core, React, and healthcare management systems.

I enjoy working on the backend side of applications, including database design, REST APIs, authentication, authorization, email integrations, background jobs, and real-time communication.

I'm also interested in building responsive interfaces with Vue.js and connecting them to reliable backend services.

Currently, I'm expanding my backend development skills through **Python, Django, and Django REST Framework**, applying the concepts I've learned from Laravel and .NET while building practical projects.

The system supports maintenance workflows, staff coordination, service request tracking, and monitoring of service-level agreements.

#### Key Features

- **Multiple portals:** Dedicated administrative and staff interfaces.
- **Role-based access control:** Permissions for different users involved in maintenance operations.
- **Email automation:** Creation of maintenance tickets from incoming Microsoft 365 emails, with duplicate prevention.

- **SLA monitoring:** Tracking of resolution times and maintenance performance.
- **Analytics dashboards:** Visibility into ticket resolution and staff workloads.
- **LDAP integration:** Integration with the university staff directory for institutional authentication.
- **QR code requests:** Submission of maintenance requests by scanning equipment or room labels.

- **Containerized infrastructure:** Docker Compose configuration for the application's supporting services.
