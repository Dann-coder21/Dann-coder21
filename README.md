## About Me

I'm a software developer based in Nairobi, Kenya, interested in building reliable web applications, well-structured backend systems, and software that solves real-world problems.

My professional experience includes developing a university maintenance management system using Laravel, Filament PHP, PostgreSQL, Redis, and Docker. I've also worked with ASP.NET Core, React, and healthcare management systems.

I enjoy working on backend functionality, including database design, REST APIs, authentication, authorization, email integrations, background jobs, and real-time communication.

I'm currently expanding my backend development skills through Python, Django, and Django REST Framework while building practical projects and strengthening my understanding of application architecture.

### Current Focus

- Developing web applications with Laravel and Vue.js.
- Building maintainable backend systems and REST APIs.
- Designing relational databases with PostgreSQL.
- Implementing authentication and role-based permissions.
- Integrating applications with external services and email systems.
- Working with Redis, background queues, and real-time notifications.
- Learning Python and Django through hands-on projects.
- Improving application testing, Docker workflows, and deployment practices.
